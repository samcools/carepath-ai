## Implemented as architecture, not yet live production capability

### PostgreSQL persistence

`apps/api/prisma/schema.prisma` defines the target persistent domain model, but runtime repositories remain deterministic/in-memory for the hackathon. No production persistence claim is permitted yet.

### MFA / enterprise SSO

Break Glass uses seeded-password re-authentication as a demonstrator. Enterprise MFA/SSO has not been deployed.

### Interoperability

The FHIR gateway and source connectors are demonstration adapters. No live NDoH, HPRS, HIE, public/private hospital, lab, pharmacy or imaging integration is claimed.

### Clinical validation

CarePath has not undergone clinical validation, SAHPRA approval or NDoH endorsement. It is not a production clinical decision system.

### Population/outcome analytics

All values are synthetic. Observed recovery/mortality values are not risk adjusted and must not be interpreted as hospital quality rankings.

## Temporary technical debt

To preserve the working v0.4 hackathon server while adding v0.5 without replacing a large monolithic `server.ts`, v0.5 routes are currently attached through a documented compatibility bootstrap in `v05Bootstrap.ts`.

The v0.5 browser experience is also loaded as a progressive module around the existing React shell. `v05-platform.ts` is currently excluded from strict web TypeScript checking because of the DOM compatibility layer, while it remains Vite/esbuild compiled; the main React application and the new typed bridge/drill-down modules remain strict-checked.

Before enterprise hardening, refactor these compatibility layers into explicit router composition and first-class React modules and restore strict TypeScript checking across the complete web codebase.
