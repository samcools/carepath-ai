# CarePath AI v0.1.0 — Hackathon executable baseline

This release is the first working CarePath AI implementation based on the canonical master prompt.

## Implemented

- Pyrneo-branded responsive web shell
- secure demo session authentication with seeded roles
- synthetic longitudinal patient records (CarePath OneRecord)
- clinical provenance for allergies, conditions, medication, results and encounters
- synthetic public/private/lab/pharmacy facility directory (CarePath Exchange demo layer)
- governed referral state machine and referral queues (CarePath Journey)
- referral leakage detection for referrals waiting more than 24 hours
- CarePath Command Centre metrics and recent governed activity
- Ayanda text assistant with deterministic grounded demo intents
- browser speech recognition / speech synthesis with one global controller and language selection
- explicit confirmation before Ayanda can create a referral draft
- append-style in-memory audit events
- responsive desktop/tablet/mobile layouts
- Render production scaffold and GitHub Actions quality checks

## Deliberate prototype limits

- all data is synthetic
- persistence is in-memory for deterministic hackathon demonstration
- no live public/private health-system integration is claimed
- FHIR interoperability is an architectural direction; formal conformance testing is not claimed
- Ayanda does not diagnose, prescribe or make autonomous clinical decisions
- browser speech quality depends on the available OS/browser language voices
